# GameCharacterBuilder
This project demonstrates the Builder Design Pattern for creating game characters.

## Characters

- Spider Man
- Green Goblin

## Structure

- `character.java` - Product
- `characterBuilder.java` - Builder
- `spiderManBuilder.java` - Spider-Man builder
- `greenGoblinBuilder.java` - Green Goblin builder
- `characterDirector.java` - Director
- `Main.java` - Client

## How to Run

1. Open the project in IntelliJ IDEA.
2. Open `src/builder/Main.java`.
3. Run the `main()` method.
4. The created characters will be displayed in the console.

The program creates and displays Spider-Man and Green Goblin.
